# 紫微斗數・八字排盤

[![Deploy to GitHub Pages](https://github.com/xciv0904/ziwei-bazi-engine/actions/workflows/deploy.yml/badge.svg)](https://github.com/xciv0904/ziwei-bazi-engine/actions/workflows/deploy.yml)

結合紫微斗數與八字的免費線上排盤網站。輸入生辰後，即可查看十二宮命盤、八字四柱、主題分析、近期運勢與分層白話解讀。

所有排盤與規則解讀都在瀏覽器內完成，不會把生辰資料上傳到伺服器，也不需要呼叫外部 AI API。

**線上使用：[xciv0904.github.io/ziwei-bazi-engine](https://xciv0904.github.io/ziwei-bazi-engine/)**

## 閱讀方式

網站將命盤內容分成四個用途，避免原始資料與長篇分析混在一起：

- **命盤總覽**：查看命盤裡有什麼，包括宮位、星曜、四化、八字、大限與流年。
- **主題分析**：從生活中的具體問題開始，直接閱讀紫微與八字的綜合初步回答。
- **重點解讀**：快速掌握本命、現行大限與流年中，目前最值得注意的方向。
- **深度解析**：閱讀性格、工作、感情、家庭與人生模式等較完整的長篇分析。

閱讀模式有兩段，可在命盤總覽、重點摘要與完整報告的頁首切換：

- **白話模式**：只看結論。全站不出現亮度、四化、十神這類術語，連收合的專業區塊都不顯示。
  每段結論下方有「為什麼這樣判斷？」可展開，用白話說明這段話用了命盤上的哪幾項資料。
- **學習模式**：術語與完整依據都給，但**每一塊都必須說明它從命盤哪裡來**。
  命盤總覽多出「逐步判讀」教學區；重點摘要與完整報告的每一段下方多出「這段話的依據從哪裡來」，
  列出用到的盤面資料、寫成「因為…所以…」的推導，並可一鍵跳回命盤總覽的那一宮把同一件事走一遍。

原本還有第三段「專業模式」，已經併進學習模式。原因是實測發現：學習模式在組裝文字時等同白話模式，
所以除了命盤總覽以外兩者一模一樣；而「專業命理依據」那塊不看模式照常顯示，白話模式反而混進了術語。
三段名義上存在、實際上只有兩種畫面，還把術語漏進了不該有術語的那一段。
現在的界線只有一條：白話模式不出現術語，學習模式出現術語就一定要交代來源。

## 主要功能

### 紫微學習模式（逐步判讀）

在命盤總覽切到「學習模式」後，點任一宮位就會展開逐步判讀。內容全部由目前這張命盤動態產生，
並分成三個階段，可隨時切換，選擇會被記住：

| 階段 | 步驟 | 內容 |
| --- | --- | --- |
| **初階**・認識你的命盤 | 3 步 | 主星在這一宮怎麼發揮、對宮軸線、白話結論。不碰四化與飛星。 |
| **進階**・學會判讀 | 5 步 | 加上判讀順序、廟旺、雙星、六吉六煞、三方四正綜合。四化只看生年這一層。 |
| **高級**・完整判讀 | 5 步 | 全部展開：宮干飛化、向心與離心自化、大限流年四化、雜曜、完整證據鏈。 |

五個步驟依序是：

1. **先看本宮**：依三合派的判讀順序分成六層（見下表），從主星一路帶到雜曜。
2. **看對宮**：對宮主星，以及這兩宮組成哪一條軸線、為什麼要一起看。
3. **看三方四正**：本宮、對宮與兩個三合宮並列，命盤上同步以虛線框標出這四宮。
4. **看四化與自化**：生年四化、宮干飛化、向心／離心自化、大限四化、流年四化分層列出，每一條都寫成「命宮宮干癸，使巨門化權，落入財帛宮」這種完整句子，並標明屬於本命、大限還是流年。
   大限四化與流年四化跟其他幾層不同：它們由大限天干與流年天干決定，是這十年、這一年共通的四條，
   不會因為你在看哪一宮而改變。所以這兩組會分成兩層——先列落在本宮的（沒有就明說沒有，那本身就是一個判斷），
   其餘收合並註明「每一宮看到的都一樣」，避免誤以為是重複顯示。
5. **整合成白話**：分成主要依據、輔助依據、暫時不採用，再收斂成四段結論（盤面看到什麼 → 資料怎麼互相影響 → 可能出現在什麼情況 → 還需要什麼才能確認），最後附上判讀限制。

第一步依三合派的判讀順序分層，教的是「先看哪一個、每一層怎麼改變判斷」：

| 順序 | 內容 | 為什麼在這個位置 |
| --- | --- | --- |
| ① | 主星 | 這一宮由誰主導，是判斷的骨架；空宮借對宮 |
| ② | 廟旺利陷 | 同一顆星在不同地支力量差很多 |
| ③ | 雙星組合 | 兩顆主星要當成新的組合讀，不是特質相加 |
| ④ | 生年四化 | 決定能量往哪走，屬於主結構 |
| ⑤ | 六吉六煞 | 改變力道與方式，不改變主題 |
| ⑥ | 雜曜 | 最後才看，補「以什麼形式呈現」 |

每一顆星名都可以點開：滑過看定義，點擊跳到命理小百科的完整詞條。

**每顆星落在這一宮會怎樣**，資料來自 `src/data/star-palace-application.json`（824 條），
學習模式與命理小百科共用同一份，兩邊不會有落差：

- **十四主星**：12 宮 × 14 星 × 3 項 = 504 句，每格給「最能發揮／要注意／怎麼做」。
- **雙星組合**：23 組 × 12 宮 × 2 項 = 552 句（`src/data/double-star-palace.json`），
  每格給「落在這一宮是什麼樣子」與「這一組的取捨」。
  雙星的一句話介紹本身難懂，是因為它必須落在某一宮才有意義——
  同一組落在命宮與落在夫妻宮講的是兩回事。
- **六吉、六煞、祿存天馬**：14 星 × 12 宮 = 168 條，逐宮列出落宮影響。
- **其餘雜曜**：38 星 × 4 類宮位（六親宮、財官宮、疾厄福德、遷移僕役）= 152 條。
  雜曜不逐宮窮舉，是因為同類宮位的差異很小，硬寫 480 條只會變成換名詞的灌水。

命理術語旁邊一律附白話翻譯，回答的是「所以我的生活裡會怎樣」。顯示方式依閱讀模式切換：
白話模式只給白話句、學習模式白話在前術語在後、專業模式只給術語句。例如同一條宮干飛化：

> **術語**：宮干飛化（宮位之間）：財帛宮宮干己使武曲化祿，落入僕役宮。
>
> **白話**：你在金錢與收入的付出，會把資源與機會帶到朋友與合作對象。這兩塊在你身上是連動的：金錢與收入順的時候，朋友與合作對象通常也跟著好。

第三步除了四宮表格，還會把四宮合起來說成一件事（「這四件事是同一組，會互相牽動」）；
第五步的結論每一句都寫成「因為…所以…」並標出依據來自第幾步，可以往回查。

其他配套：

- **空宮借星教學**：遇到沒有十四主星的宮位時，先說明空宮不代表沒有能力，接著講清楚借星安宮到底怎麼借——
  **借的是「星」，不是「宮」**：主星本身、它的廟旺利陷、它帶的生年四化會跟著過來（那些是星的屬性）；
  對宮的輔星煞曜雜曜、對宮的宮干與飛化、對宮的宮位主題留在原地（那些是宮位的東西）。
  畫面會直接列出這張盤實際借到什麼（例如「太陽（亮度得）、太陰（亮度不）」）、哪些留在對宮，
  以及本宮自己有什麼。借來的若是雙星，另外說明兩顆怎麼分主從。
  本宮自己已有吉星或煞星時，會註明「是否仍要借星」各家講法不同，本站不替使用者選邊。
- **先自己判斷**：依當前命盤產生選擇題，答完才顯示正解與理由。題目只考盤面查得到的事實，不考流派爭議。
  題目分三類，會隨著你答對而逐步換掉，避免十二宮做同一份：

  | 類型 | 例子 | 什麼時候退場 |
  | --- | --- | --- |
  | 通則題 | 判讀順序、雜曜的角色、煞星怎麼看 | 答對一次就不再出（答案跟看哪一宮無關） |
  | 基本功題 | 本宮主星、對宮、三合宮、是不是空宮 | 答對三宮後退場（題型一字不差，問十二次會變成抄寫） |
  | 這一宮專屬 | 這一宮在看什麼、生年四化、廟旺、這顆星放在這一宮怎麼發揮、空宮借了什麼 | 不退場，且優先出 |

  其中「這顆星放在這一宮怎麼發揮」的誘答刻意取同一顆星在**別的宮位**的說法——
  初學者最常犯的錯就是把星的通性直接套到每一宮，這題直接考這件事。
- **學習進度**：以命盤識別碼分開記錄「十二宮學習進度：n／12」，可繼續上次學習或重設。進度存在瀏覽器 `localStorage`，識別碼是生辰的不可逆短雜湊，不含可讀的出生資料，也不會離開這台裝置。
- **名詞小百科**：命宮、身宮、空宮、對宮、三方四正、宮干、生年四化、飛化、向心／離心自化、大限、流年、小限、廟旺利陷、來因宮，滑過或點一下就地顯示說明。

教學內容不重新排盤，也不會新增命盤上沒有的結論：對宮、三方四正、自化、飛化與來因宮全部沿用既有引擎的計算結果。

### 命盤總覽

- 紫微斗數十二宮互動盤面。
- 點選宮位即可查看宮位意義、白話重點與專業命理資料。
- 自動標示命宮三方四正、大限宮位、流年命宮與流年四化落點。
- 八字四柱、十神、藏干、納音、五行分布及日主資訊。
- 大限、流年與十二流月切換。
- 流年解讀會依當事者年齡調整生活語境，避免所有年齡都只談工作。
- 流月內容分成白話重點、可以把握、需要留意與行動建議；專業術語預設收合。

### 10 類、60 題主題分析

每個類別提供 6 個具體問題，共 60 題：

| 類別 | 問題方向 |
| --- | --- |
| 愛情 | 對象類型、心動特質、相處方式、衝突修復、感情盲點、關係界線 |
| 事業 | 工作內容、職場強項、適合環境、合作角色、職涯卡點、長期方向 |
| 財運 | 收入累積、金錢習慣、財務決定、合作賺錢、管理優勢、財務節奏 |
| 父母 | 互動模式、長輩支持、家庭界線、家人期待、溝通方式、成年後距離 |
| 子女 | 晚輩互動、陪伴培育、創作產出、期待方式、意見溝通、照顧界線 |
| 幸運 | 機會狀態、助力來源、主動行動、容易忽略的機會、錯過時機、保留機會 |
| 住宅 | 居住環境、安全感、搬遷置產、同住選擇、居住資源、工作空間 |
| 健康 | 壓力反應、恢復習慣、容易忽略之處、休息節奏、精神耗損、透支警訊 |
| 人際 | 朋友類型、人際角色、合作界線、第一印象、衝突修復、適合的朋友圈 |
| 遷移 | 外出表現、往外發展、適應方法、適合環境、轉換問題、外地機會 |

每題包含：

- 針對這一題寫的專屬回答。答案取自「60 題 × 14 主星」的答案庫（`src/data/topic-star-answers.json`），依你命盤中該題對應宮位的主星取用；該宮無主星時借對宮參看。
- 以一般生活語言呈現，不直接堆疊宮位、十神或五行術語。
- 可展開的命盤依據，列出對應宮位、主星與亮度、生年四化與借星狀態，每一項都能回到命盤上核對。
- 獨立的「AI 深入回答這一題」按鈕。
- 複製時會附上完整命盤資料與該題的解讀要求。

### 重點解讀

- 紫微六大主題與八字五大主題。
- 一句話重點、生活表現、可能挑戰、具體建議與自我對照。
- 白話摘要與專業依據可切換。
- 紫微與八字分頁會各自保留閱讀模式。
- 同一時間只展開一張卡片，降低閱讀負擔。

### 完整報告：人生說明書

完整報告開頭是一份把命盤排成時間線的敘事，讓你可以拿走過的年份直接對照：

1. **你是什麼樣的人**：命宮主星（空宮則借對宮）、身宮位置，以及命盤裡比較順與比較費力的兩個方向。
2. **你的人生會怎麼展開**：十個大限逐段說明那十年的重心、會實際發生哪些事、你會用什麼方式度過，以及最容易被消耗的地方。
   每一段的內容取自「12 宮 × 14 主星」的階段文案庫（`src/data/life-stage-details.json`）：大限落在哪一宮決定主題，該宮主星決定你怎麼過這十年，
   所以同齡但命盤不同的人讀到的是不同的十年。預設展開現在這一段，其餘可點開對照。
3. **你反覆遇到的課題**：由生年四化與飛化疊加點推出，是不會因為換階段而消失的部分。
4. **你的轉折點**：大限交界換算成西元年，標出重心會換方向的時間點。

### 深度解析

- 紫微與八字各六個完整分析段落。
- 涵蓋性格、事業、感情、家庭、人生課題、全盤概覽、地支關係與神煞。
- 白話內容優先，完整命理依據預設收合。
- 適合想理解長期人生模式，而不只查看近期運勢的使用者。

### AI 解讀工具

網站不會自行呼叫 AI 服務，而是產生可複製的完整提示詞，使用者可貼到自己選擇的對話式 AI：

- 完整命盤解讀。
- 單一宮位深入分析。
- 指定流年分析。
- 單一主題問題深入回答。
- 合盤、姓名學及進階工具專用提示詞。

提示詞會保留紫微、八字、大限與流年資料，並要求 AI 不重新排盤、不補造命盤中不存在的資訊。

### 其他工具

- **命盤收藏**：使用 `localStorage` 儲存最多 20 筆命盤，資料只留在本機。
- **雙人合盤**：比較兩人的互動模式與八段關係分析。
- **命盤比對**：並排比較 2–4 筆已收藏命盤。
- **分享命卡**：產生可下載圖片、QR Code、分享連結及 LINE 分享內容。
- **姓名學**：五格剖象、三才五行、姓名五行與八字喜用神、紫微命宮主星比對。
- **進階玄學**：未來七日運勢、生涯時間軸、時辰驗盤、個人擇日、易經、梅花易數與奇門工具。
- **命理小百科**：190 個詞條，分成四層：總索引 → 分區 → 分類 → 詞條，點哪個分類就只看到那一類。
  三個分區的用意是避免兩套系統與兩個派別混在同一份清單：
  - **紫微斗數・三合派（南派）**：十四主星、23 組雙星組合、十二宮位、六吉、六煞、祿馬、空亡、雜曜、四組十二神、四化。
  - **紫微斗數・飛星派（北派）**：自化、宮干飛化、來因宮。
  - **八字**：十神、神煞、地支關係。

  命盤上會顯示的 94 顆星曜每一顆都查得到，而且在命盤總覽點星名就會直接開對應詞條。
  八字神煞與紫微星曜有五條同名（孤辰、空亡、喪門、劫煞、將星），八字側加上「(八字神煞)」後綴區分，
  兩邊的頁面也互相標註提醒是不同系統的概念。
- **PWA**：可加入手機主畫面並支援離線使用。

## 隱私與資料處理

- 排盤計算在使用者的瀏覽器中執行。
- 生辰資料不會傳送至本站伺服器。
- 收藏資料只儲存在目前裝置的瀏覽器中。
- 複製給 AI 的內容只有在使用者自行貼到第三方服務時才會離開瀏覽器。

## 技術架構

- **紫微排盤**：[iztro](https://github.com/SylarLong/iztro)。星曜位置採該套件預設演算法。
- **四化表**：庚干太陰化科、壬干左輔化科、戊干右弼化科，屬欽天／飛星系統的版本，與 iztro 的生年四化同一張表。
  已用文墨天機命盤逐宮交叉驗證（見 `cross-test-wenmo.mjs`，25 項全數吻合）。各派四化表在庚、壬兩干差異最大，
  改用其他版本會變動所有人的四化落點與自化結果，屬於受保護的計算約定。
- **解讀觀點**：文案與小百科詞條以三合派（南派）為主；自化、宮干飛化、來因宮屬飛星派（北派）方法，
  在小百科中獨立成類並標明派別，兩套系統不混用。
- **八字與曆法**：[lunar-javascript](https://github.com/6tail/lunar-javascript)。
- **前端**：Vite + Vanilla JavaScript。
- **解讀引擎**：`src/engines/` 內的規則組裝邏輯。
- **內容資料**：`src/data/` 內的命理資料與白話內容庫。
- **測試**：核心排盤回歸測試、術數計算測試及 happy-dom UI 煙霧測試。
- **部署**：推送至 `main` 後，由 GitHub Actions 測試、建置並部署至 GitHub Pages。

## 本機開發

需要 Node.js 與 npm。

```bash
git clone https://github.com/xciv0904/ziwei-bazi-engine.git
cd ziwei-bazi-engine
npm install
npm run dev
```

Vite 啟動後，依終端機顯示的本機網址開啟網站。

## 測試與建置

```bash
npm test
npm run smoke
npm run build
```

- `npm test`：核心排盤值與術數計算回歸測試。
- `npm run smoke`：主要頁面、互動、主題分析、學習模式、AI 複製與重新排盤流程測試。
- `npm run build`：產生命理小百科及 GitHub Pages 部署版本。

其他驗證工具：

```bash
node cross-test.mjs
node cross-test-bazi.mjs
npx vite build --mode singlefile --outDir dist-single
```
